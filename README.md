# Export Controls Watch: published output

This repository is the published output of Export Controls Watch: a static site, an
RSS feed and two datasets, regenerated by an automated pipeline. The pipeline itself is
not in this repository. Every commit here is a site rebuild.

Site: https://rikiosso.github.io/exports-watch/ · Feed: [`rss.xml`](rss.xml)

## What is covered

In scope: BIS rules under the EAR and the BIS lists (Entity List, Denied Persons,
Unverified, Military End User), ITAR debarments, State Department nonproliferation
designations, and Annex I of Regulation (EU) 2021/821 including corrigenda. Not
covered: OFAC sanctions programmes, tariff and import actions.

Editorial policy: the pipeline publishes only notes it rates medium or high
confidence. Every citation on a note published since 11 September 2026 links to its
source; a note where any citation cannot be resolved to a canonical url is held
instead of published.

## What is here

| Path | What it is | Consumers |
|---|---|---|
| `data/annex.json` | Annex I of Regulation (EU) 2021/821 (the EU dual-use list), consolidated text, one line per provision, plus Annex II general export authorisations, the definitions annex, general notes and Articles 2/4/5. | [EU Dual-Use Classifier](https://github.com/rikiosso/dualuse-classifier) reads it at runtime. |
| `data/notes.json` | Machine-drafted notes on export-control changes, with citations. | The site, the feed. |
| `data/status.json` | Last-checked timestamp and publish counters for this build. | Monitoring the pipeline from outside it. |
| `index.html`, `notes/*.html`, `rss.xml` | Rendered site. | People. |

## `annex.json`

Rebuilt from the EUR-Lex CELLAR consolidated text on a schedule; corrigenda applied in
place by EUR-Lex are picked up on the next run (the February 2026 corrigendum to
3B501.f.1.a is reflected). Top-level fields:

```
corpus_version   e.g. "02021R0821-20251115"  (CELEX id + consolidation date)
celex            "02021R0821"
valid_from       consolidation date of the text
retrieved_at     when this file was built
sha256           of the source document
source_url       CELLAR resource the text came from
attribution      EU reuse notice
entry_count      384
index[]          { code, first_line }                       -- cheap listing of every entry
entries[]        { entry_code, category, verbatim_text,      -- full text, one provision per line,
                   parameters[], applicable_notes[] }          dotted paths as printed (3B501.f.1.b.1)
docs[]           { doc_type, title, verbatim_text }         -- general notes, definitions, Articles
geas[]           { id, title, verbatim_text }               -- EU001…EU008 (Annex II)
gea_common_list  Annex II section I common excluded-items text
```

Only the Official Journal of the European Union is authentic. Annex text © European
Union, reuse permitted with acknowledgment (Commission Decision 2011/833/EU).

## `notes.json`

One object per note, restricted to notes whose linked event is in scope (see above).
Fields the pipeline fills reliably are marked ●; the rest are frequently
`"not stated in source"` or empty and should be treated as optional.

```
● id, headline, action_date, archived_on, status
● what_changed, who_is_affected          prose, with inline citation keys in [brackets]
● instruments[]                          list names as the source prints them (not normalised)
● citations[]  { pinpoint, url|null }    url is null only for notes published before
                                          11 September 2026 where no canonical page
                                          could be resolved; every citation on a note
                                          published since links to its source
● confidence   "high" | "medium"          low-confidence drafts are held, never published
  relevance_eu_exporters                 usually "indirect only"; occasionally a paragraph
  action_items[], effective_dates[], licence_posture
  entries_affected[], parameter_deltas[], national_lists_touched[]
  reclassification_impact, licence_impact, materiality, series_500_flag, event_refs[]
```

## Changes on 11 September 2026

1. **Scope filter.** Notes are published only when their linked event is in scope (see
   "What is covered" above). OFAC/Treasury sanctions-only list updates, tariff and
   import-adjustment notices, and public-inspection listings are out of scope and do
   not appear on the site, the feed or in `notes.json`.
2. **Event de-duplication.** A cosmetic re-formatting of an existing list entry no
   longer produces a new note.
3. **Citation urls or hold.** Every citation on a note published since this date
   resolves to a canonical url (Federal Register documents, CSL/OFAC entity pages,
   EUR-Lex CELEX resources) or the note is held rather than published bare.
4. **Encoding guard.** A citation string that carries a control character, a decode
   error, or a stray trailing byte is cleaned before it reaches this site.
5. **Last-checked stamp.** The site and `data/status.json` now show when the pipeline
   last ran, whether or not that run produced a new note, so a quiet period on the
   page can be told apart from a stopped pipeline.
6. **Medium-or-high policy.** Only notes the pipeline rates medium or high confidence
   publish; low-confidence drafts are held.
7. **This README** replaces an earlier version whose "known problems" list is now
   fixed; see "Still open" below for what is not.

## Still open

- The data licence has not been declared. CC BY 4.0 would fit the EU attribution
  requirement (Commission Decision 2011/833/EU); this is the author's decision to
  make, not yet made.
- Notes published before 11 September 2026 keep a null `url` on any citation where no
  canonical page could be resolved at the time. They are not retroactively re-resolved.
